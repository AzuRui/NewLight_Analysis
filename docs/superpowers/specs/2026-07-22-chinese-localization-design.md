# NewLight_Analysis 完整中文化设计

## 目标

将 NewLight_Analysis 的用户界面完整中文化，包括主界面、参数面板、弹窗、文件选择器、运行日志、错误提示、状态文本和分析图表。模型、算法和常用科研缩写保留原始名称，并补充简明中文功能名称。

本次只修改显示语言和必要的布局宽度，不改变分析算法、文件格式、参数默认值或处理流程。

## 命名规范

- 模型或项目名称保留原文，后接中文功能名。
- 通用科研缩写保留原文，包括 ROI、dF/F、FPS、CUDA、AVI、TIFF、JSON、PNG、px。
- 长按钮名称在不丢失主要含义时适当精简。
- 同一功能在按钮、参数标题、日志和弹窗中使用一致名称。

主要功能名称：

| 内部功能 | 中文显示名称 |
| --- | --- |
| CaImAn Motion | CaImAn 运动矫正 |
| Rigid Motion (Built-in) | 内置刚性运动矫正 |
| DeepCAD-RT | DeepCAD-RT 深度学习降噪 |
| NeuroSeg3 Auto ROI | NeuroSeg3 自动 ROI 分割 |
| NeuroAlign | NeuroAlign 脑图谱配准 |
| Atlas Reference Builder | 标准图谱构建 |
| Built-in Auto ROI | 内置自动 ROI |
| Image Shift | 图像行偏移校正 |

CaImAn 的描述和帮助文本明确说明它用于运动矫正/去抖动，不在按钮上重复过长的斜杠名称。

## 实现方案

### 内部标识与显示文本分离

预处理功能、模型和操作分支继续使用稳定的英文内部 ID。界面按钮只显示中文标签，点击后把内部 ID 传给现有处理函数。

不得使用翻译后的文本进行算法选择、字典查找或条件判断。这样可以避免修改按钮文字后导致功能失效。

### 中文显示范围

以下用户可见内容全部中文化：

- 主窗口标签页、分组标题、按钮、单选框、复选框和状态栏
- 左侧参数面板的参数名称、说明和操作按钮
- 所有设置窗口、向导步骤、帮助窗口和颜色选择窗口
- 文件打开、保存和目录选择窗口的标题及文件类型说明
- 信息、警告和错误弹窗
- 应用运行日志和处理完成提示
- Matplotlib 图表标题、坐标轴、图例和无数据提示
- 后台任务在主应用中呈现的摘要信息

外部依赖直接输出的原始日志可以保留必要的英文技术信息，但主应用添加的前缀、状态和错误摘要使用中文。

### 布局调整

- 左侧功能栏内的操作按钮使用统一宽度和统一对齐方式。
- 适度增宽左侧功能栏，使最长的精简中文名称完整显示。
- 参数栏和主显示区域随功能栏宽度重新分配，不遮挡日志、工具栏或图像。
- 不使用字体随窗口宽度缩放；通过固定最小宽度和响应式剩余空间保证布局稳定。
- 在常用桌面尺寸和最大化窗口下检查文字截断和控件重叠。

## 兼容性

- 不修改已保存项目、ROI、图谱、协议或预处理配置中的内部键名。
- 不修改 worker 命令行参数、环境名、模型目录或输出文件命名规则。
- 程序窗口标题 `NewLight_Analysis` 保持不变。
- 源码启动和 PyInstaller 编译版使用相同中文文本，不额外引入语言包依赖。

## 测试与验收

### 自动测试

- 验证四个主标签页和主要功能按钮显示预期中文名称。
- 验证模型名称同时包含原始名称和中文功能说明。
- 验证中文预处理按钮仍映射到原有内部 ID 和处理函数。
- 扫描主要界面定义，防止约定范围内的用户可见英文重新出现。
- 运行现有 GUI 静态测试、功能测试和 Python 语法检查。

### 界面烟测

- 通过源码启动应用并检查各标签页、参数栏和主要弹窗。
- 检查普通窗口和最大化窗口下按钮宽度一致、文本完整、图像区域居中且无重叠。
- 运行一次 CaImAn 参数面板和至少一个 ROI/分析弹窗，确认中文化未改变调用路径。

- 本次不翻译第三方模型名称、文件扩展名或科研缩写。
- 本次不重新设计整体视觉主题。
- 本次不重新编译 EXE；代码验证完成后再按用户指示编译。
