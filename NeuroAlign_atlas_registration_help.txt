NeuroAlign help
================

This tool has two related steps:

1. Atlas Reference Builder
   Builds a clean reference atlas JSON from a line-drawing atlas image.

2. NeuroAlign
   Warps that reference atlas onto the current subject video and loads the
   warped atlas regions back into the ROI list.


Atlas Reference Builder
-----------------------

Input image:
  A clean atlas line image. Best input is black background with bright region
  boundaries and no text labels.

Line threshold:
  Brightness cutoff for extracting atlas boundary lines.
  If important boundaries disappear, lower it.
  If background noise becomes boundary lines, raise it.

Bridge gap px:
  Maximum small gap distance that the builder will automatically connect.
  Raise it when atlas lines have small breaks.
  Lower it if unrelated boundaries get connected.

Barrier radius:
  Thickens boundary lines before finding enclosed regions.
  1 is a good starting point.
  Raise only if regions leak through thin boundaries.
  Lower to 0 if neighboring regions get merged.

Min region area:
  Removes tiny enclosed fragments.
  Raise it if many tiny false regions appear.
  Lower it if real small brain regions are missing.

Detect dark lines:
  Enable this only for white/light background images with dark atlas boundary
  lines.

Main outputs:
  atlas_regions_raw.json
  atlas_preview_ids_colored.png
  atlas_preview_filled.png
  brain_line_mask_completed.png


NeuroAlign
----------

Backend:
  NeuroAlign runs through the caiman_latest conda environment. That environment
  must contain sklearn, python-igraph, and leidenalg.

Video:
  Subject video to align. By default this is the current opened movie path.

Atlas JSON:
  Reference atlas JSON. Usually use the atlas_regions_raw.json generated by
  Atlas Reference Builder.

Output dir:
  Folder for the full registration report and all intermediate files.

Brain mask percentile:
  Controls how conservative the subject brain mask is.
  Raise it when the mask includes background or fills the midline.
  Lower it when the mask misses real brain tissue.
  Good first test: 72.

Midline anchors:
  Number of midline control points.
  Raise it when the atlas midline does not follow the subject midline.
  Good first test: 14.

Midline weight:
  Strength of the midline constraint during warping.
  Raise it when the midline is detected but does not affect the final warp.
  Good first test: 8.

Outer weight:
  Strength of the outer brain contour constraint.
  Lower it when the outer contour is overpowering the midline or local warp.
  Good first test: 0.5.

TPS smooth:
  Smoothness of local nonlinear warping.
  Higher values are stiffer.
  Lower values allow stronger local bending.
  Good first test: 3.

Max ctrl shift px:
  Maximum allowed control-point movement.
  Raise it when TPS is too restricted to bend into the correct location.
  Good first test: 24.

Min inner ctrl:
  Minimum inner-boundary control points required before TPS is allowed.
  Lower it if TPS is never attempted because too few inner points are found.
  Good first test: 4.

Auto rerun attempts:
  Number of adaptive retry attempts.
  Raise it when the result is unstable and you want the script to search more
  parameter combinations.
  Good first test: 8.


What to inspect first
---------------------

Open these files after a run:

1. subject_outer_mask.png
   Confirms whether the subject brain mask is too large, too small, or merged
   through the midline.

2. midline_profile_overlay.png
   Confirms whether the midline / fissure profile is detected in the right
   place.

3. final_warp_overlay.png
   Shows the final warped atlas boundary overlay.

4. final_warp_segmentation_overlay.png
   Shows the warped atlas regions as filled segmentation.

5. registration_summary.json
   Check delivered_mode, n_inner_ctrl, affine_warp_score, final_warp_score,
   and subject_midline_reliability.


Quick tuning guide
------------------

If the mask swallows background or the midline:
  Increase Brain mask percentile.

If the midline is detected but the result ignores it:
  Increase Midline weight and Midline anchors.
  Decrease Outer weight.

If the atlas refuses to bend:
  Decrease TPS smooth.
  Increase Max ctrl shift px.

If TPS is never used:
  Decrease Min inner ctrl.
  Increase Auto rerun attempts.

If the atlas bends too much or becomes distorted:
  Increase TPS smooth.
  Decrease Max ctrl shift px.
  Increase Outer weight slightly.


Recommended first trial
-----------------------

Brain mask percentile: 72
Midline anchors: 14
Midline weight: 8
Outer weight: 0.5
TPS smooth: 3
Max ctrl shift px: 24
Min inner ctrl: 4
Auto rerun attempts: 8
